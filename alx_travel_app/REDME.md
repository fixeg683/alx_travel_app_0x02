# ALX Travel App with Chapa Payment Integration

## 🚀 Project Overview
A Django-based travel booking application with secure payment processing through Chapa API.

## 📋 Features
- Property listings with search and filtering
- Booking management system
- Chapa API payment integration
- Email notifications with Celery
- RESTful API with Django REST Framework
- User authentication and authorization
- Admin dashboard for management

## 🛠️ Tech Stack
- **Backend**: Django 4.2, Django REST Framework
- **Database**: PostgreSQL
- **Payment**: Chapa API
- **Async Tasks**: Celery with Redis
- **Email**: SMTP with Celery tasks
- **Frontend**: Django Templates (can be extended to React/Vue)
